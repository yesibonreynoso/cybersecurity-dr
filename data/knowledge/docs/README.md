# Carpeta de documentación

Esta carpeta está pensada para almacenar documentos de referencia que el agente pueda consultar.

## Formatos recomendados

- CSV
- Markdown (.md)
- Texto (.txt)
- PDF

## Cómo usarla

1. Coloca tus documentos aquí.
2. Luego súbelos desde la interfaz del chatbot.
3. El agente podrá responder preguntas sobre ellos.
